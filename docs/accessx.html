accessX documentation

Network-based accessibility analysis for X-minute cities, proximity planning, and urban opportunity mapping.

Citing accessX

If you use accessX in academic work, please cite the accompanying paper or software record.

Link

accessX is a Python package for network-based accessibility analysis. It supports reproducible workflows for X-minute-city analysis, proximity planning, opportunity mapping, co-accessibility, and equity assessment.

What does X mean?The X can be any network cost threshold: walking minutes, cycling time, distance, generalized cost, or a custom edge-weight measure.

Installation

Install accessX from PyPI or from a local source checkout.

Install from PyPI

Install the current release with pip.

pip install accessx

Install from source

For local development from a cloned repository, install the package in editable mode.

git clone https://github.com/TransformTransport/accessX.git
cd accessX
pip install -e .

Python 3.10 or newer is required.

accessX 0.1.1

Getting Started

Run a minimal end-to-end accessibility workflow.

Minimal workflow

This example creates origins, builds a walking network, adds a time cost, retrieves POIs, and counts reachable opportunities.

import accessx as acx
import osmnx as ox

# Area of interest and origins
aoi = ox.geocode_to_gdf("Municipality of Athens, Greece")
hexes = acx.make_hex_grid(aoi, resolution=9)

# Walking network and travel-time cost
graph = acx.build_network(
    aoi,
    city_epsg=2100,
    buffer_m=1000,
    network_type="walk",
    show_progress=True,
)
graph = acx.add_time_cost_constant_speed(
    graph,
    speed_kmh=4.5,
    cost_col="walk_time",
)

# OpenStreetMap POIs grouped into analytical categories
pois = acx.get_pois_osm(
    aoi,
    poi_groups={
        "healthcare": {"amenity": ["pharmacy", "clinic", "doctors"]},
        "open_space": {"leisure": ["park", "playground", "garden"]},
    },
    show_progress=True,
)

# Cumulative opportunities within 15 walking minutes
counts = acx.count_accessible_pois(
    graph,
    hexes.to_crs(2100),
    pois.to_crs(2100),
    max_cost=15,
    cost_attr="walk_time",
    show_progress=True,
)
